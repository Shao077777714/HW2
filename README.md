# 天空島 · Sky Island

在雲海中探索草地、水、火、岩漿、地獄五種方塊空島，與會移動的豬、羊、狗一起生活。

## 啟動

1. Windows 電腦需已安裝 Node.js（此開發電腦已具備）。
2. 雙擊本資料夾的 **啟動天空島.cmd**，瀏覽器會自動開啟遊戲。
3. 點擊 **開始探索**。請保持啟動視窗開啟；關閉它會停止本機靜態預覽。

也可以在本資料夾執行 `npm start`，再開啟 <http://127.0.0.1:4173>。若 4173 已被占用，可在 PowerShell 先執行 `$env:PORT = '4174'`，再啟動並使用對應網址。

遊戲是純前端靜態網站，沒有後端遊戲伺服器、帳號或連線功能。本機預覽程式只提供檔案，並只監聽 `127.0.0.1`。由於瀏覽器對 JavaScript 模組的限制，請透過上述網址啟動，勿直接雙擊 index.html。three.js 與素材已放在資料夾內，遊玩時不需要網路或安裝 npm 相依套件。

## 操作

| 按鍵 | 功能 |
| --- | --- |
| WASD／方向鍵 | 移動 |
| 滑鼠 | 轉動視角 |
| 空白鍵 | 跳躍（離開淺水池時也可跳出） |
| 按住左鍵 | 挖掘；放開或換目標會重新計時 |
| 走近掉落物 | 自動撿取，物品欄數量增加 |
| 右鍵 | 在瞄準方塊旁放置目前選取的方塊 |
| 1–8／滑鼠滾輪 | 選擇物品；也可點選物品欄 |
| R／天氣按鈕 | 切換晴天與下雨 |
| M／全島鳥瞰 | 查看整個世界，再點擊繼續探索 |
| F／全螢幕按鈕 | 切換全螢幕 |
| Esc | 暫停並釋放滑鼠 |

若瀏覽器無法鎖定滑鼠，可按住畫面拖曳來觀看，配合 WASD 移動。鍵盤、滑鼠是主要操作方式；小螢幕可顯示畫面，但本版沒有觸控移動按鈕。

## 遊戲規則

- 整個可編輯世界位於同一個 32 × 32 × 32 格範圍，五座島透過橋梁連接。
- 草地島有豬、羊、狗各一隻，會走動、停留、轉向及避開島邊、牆壁和危險區。玩家可以穿過動物，但不能把方塊放進動物身體裡。
- 泥土需持續挖約 0.65 秒，石頭需約 2 秒；掉落物會彈起、落地及旋轉。靠近約 1.45 格才會吸入物品欄。
- 水島是有實體池底的淺水池，涉水時速度降低。火與岩漿會讓玩家回到安全出生點；原有物品與世界保留。
- 地獄島使用深紅、黑色調及火焰。一般方塊可挖取，水面、火與岩漿為固定區域，不列入物品欄。
- 下雨只改變天氣，不熄火或改變岩漿。
- 若出生點失效，會尋找草地島其他安全位置；完全沒有安全位置時會顯示重新開始選項。
- **本版不儲存進度**。重新整理頁面或重新開始會還原世界與物品欄。

## 驗證

- `npm test`：執行核心玩法、雨滴回收、動物及主題島規則的自動測試。
- `node tests/browser.mjs`：選用的 Chrome 瀏覽器操作測試，需安裝 Playwright 或以 `PLAYWRIGHT_PATH` 指定其套件目錄，並先啟動本機預覽。
- `node tests/stress.mjs`：選用的 60 秒雨天、六隻動物整合測試；條件同上。
- 詳見 `QA_REPORT.md`。目標學校舊電腦的全螢幕 30 FPS 驗收仍須在實際設備執行。

## 檔案

`index.html`、`style.css`、`app.js` 為畫面；`core.js` 為世界與核心規則；`animals.js`、`weather.js` 為新增功能；`assets/` 與 `vendor/` 為本機素材及 three.js。

規劃見 `AGENT.md`、`BRIEF.md`、`PLAN.md`，老師的測試清單見 `VERIFY.md`。
